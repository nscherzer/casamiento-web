# casamiento-web

Web del casamiento de Julia y Nico (9 de octubre de 2027, Buenos Aires). MVP: foto, fecha y cuenta regresiva, en español y alemán.

- Todo en `index.html` (sin build). Textos en el objeto `T`; fecha/hora de la cuenta regresiva en `TARGET`.
- La foto es `foto.jpg` en la raíz (vertical, ~4:5). Si no está, se muestra un monograma.
- Idioma: botón ES/DE, `?lang=de` en el link, o el idioma del navegador. Se recuerda en `localStorage`.
- Publicada con GitHub Pages desde `main`.
